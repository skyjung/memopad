# memopad

A free, local-first TypeScript prototype for distraction-free, AI-free writing with a separate Sources desk and a composition record. It does not host documents or require an account.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal. Notes and sources are stored in browser `localStorage`.

## Included

- Paste and drag/drop are blocked in the manuscript.
- Pasting is allowed in Sources for links, clippings, and quotations.
- Notes, sources, folders, search, and process metrics persist locally.
- Export downloads a self-contained HTML document with a **Written in memopad** mark.
- No document content is uploaded or hosted.

This prototype records activity inside the editor; it does not claim to prove that a writer never consulted outside tools.
